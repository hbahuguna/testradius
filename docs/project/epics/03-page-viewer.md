# Epic 3: Page Viewer Shell

**Theme**: "See the page." Electron app with embedded Playwright browser panel.

**Dependencies**: Epic 1

---

## Stories

| # | Story | Effort |
|---|-------|--------|
| 3.1 | URL bar + navigation controls (back, forward, refresh) | 1d |
| 3.2 | Embedded browser panel (Playwright managed view) | 2d |
| 3.3 | Page loading with networkidle wait + error handling | 1d |
| 3.4 | DOM extraction bridge (inject JS → structured data to backend) | 3d |
| 3.5 | Developer tools panel (view raw HTML, element tree) | 1d |
