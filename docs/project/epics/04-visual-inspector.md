# Epic 4: Visual Inspector + COM Generation

**Theme**: "Point and generate." Hover/click to select components, instantly see COM code.

**Dependencies**: Epic 2 + Epic 3

---

## Stories

| # | Story | Effort |
|---|-------|--------|
| 4.1 | Hover overlay — highlight element under cursor | 2d |
| 4.2 | Component boundary detection — expand to logical component | 2d |
| 4.3 | Click-to-select — selected component highlighted | 1d |
| 4.4 | COM code preview panel — real-time Python with syntax highlighting | 2d |
| 4.5 | Component library sidebar — all detected components | 2d |
| 4.6 | Copy/download generated COM | 1d |
